# Entwicklungsstände: von der Idee zur Übergabe

Diese Reihe dokumentiert Markus Schwarz' Entwicklung einer menschlich geführten Einstiegsphase in die Zusammenarbeit mit KI. Sie beginnt beim Anliegen und endet bei der bestätigten Übernahme durch einen ausgewählten Akteur.

**Redaktioneller Stand:** 19. November 2026. Alle Kapitel wurden an diesem Datum rückblickend erstellt. Das Datum im Ordner bezeichnet den behandelten Entwicklungsstand, nicht das Schreibdatum und nicht automatisch das erstmalige Auftreten einer Idee.

Das ist eine Entwicklung mit Verzweigungen, keine lückenlose lineare Implementationsgeschichte. Spätere Regeln werden nicht rückwirkend aktiviert.

Jedes Kapitel trennt Ausgangsfrage, Begriffe, Idee, beobachteten Stand, Übergabepunkt und Quellen. Ein Entwurf wird nicht nachträglich zum funktionierenden Werkzeug erklärt.

Die frühe Namensfolge beginnt mit STARTER / AUSRICHTER. SYNCHRONIZER ist heute ein Modus des ADVISOR; ein früheres eigenständiges Projekt dieses Namens ist hier nicht belegt.
